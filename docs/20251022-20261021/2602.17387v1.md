## 摘要
当前最先进的手写文本识别（HTR）系统通常使用Transformer，其不断增长的键值（KV）缓存使解码速度慢且内存占用高。我们提出DRetHTR，一种基于保留网络（RetNet）的仅解码器模型。与同等规模的仅解码器Transformer基线相比，DRetHTR在保持准确率不变的情况下，推理速度提升1.6-1.9倍，内存使用减少38-42%。通过用无softmax的保留机制替代softmax注意力并注入多尺度序列先验，DRetHTR避免了不断增长的KV缓存：解码在时间和内存上均与输出长度呈线性关系。为了恢复注意力的局部到全局归纳偏置，我们提出逐层gamma缩放，在更深层逐步扩大有效保留范围。这促使浅层建模短程依赖，深层捕获更广泛的上下文，从而缓解移除softmax带来的灵活性差距。因此，DRetHTR在IAM-A（英文）、RIMES（法文）和Bentham（英文）上分别取得了已报道的最佳测试字符错误率2.26%、1.81%和3.46%，并在READ-2016（德文）上以4.21%保持竞争力。这表明仅解码器RetNet能够实现Transformer级别的HTR准确率，同时显著提升解码速度和内存效率。

## Abstract
State-of-the-art handwritten text recognition (HTR) systems commonly use Transformers, whose growing key-value (KV) cache makes decoding slow and memory-intensive. We introduce DRetHTR, a decoder-only model built on Retentive Networks (RetNet). Compared to an equally sized decoder-only Transformer baseline, DRetHTR delivers 1.6-1.9x faster inference with 38-42% less memory usage, without loss of accuracy. By replacing softmax attention with softmax-free retention and injecting multi-scale sequential priors, DRetHTR avoids a growing KV cache: decoding is linear in output length in both time and memory. To recover the local-to-global inductive bias of attention, we propose layer-wise gamma scaling, which progressively enlarges the effective retention horizon in deeper layers. This encourages early layers to model short-range dependencies and later layers to capture broader context, mitigating the flexibility gap introduced by removing softmax. Consequently, DRetHTR achieves best reported test character error rates of 2.26% (IAM-A, en), 1.81% (RIMES, fr), and 3.46% (Bentham, en), and is competitive on READ-2016 (de) with 4.21%. This demonstrates that decoder-only RetNet enables Transformer-level HTR accuracy with substantially improved decoding speed and memory efficiency.

## 1. 核心问题与研究背景

- **问题定位**：手写文本识别（HTR）的主流方案已从 HMM、BiLSTM+CTC 演进到 Transformer 架构（如 TrOCR、DTrOCR）。Transformer 精度高，但自回归解码时需维护随输出长度线性增长的 KV 缓存，导致**解码慢、显存占用高**，长序列场景尤为突出。
- **已有折中方案**：RNN 每步解码成本恒定、内存线性增长，但无法并行训练；RetNet 通过"并行训练 + 循环推理"的无 softmax 保留机制（retention）兼顾两者，理论上适合 HTR。
- **核心矛盾**：RetNet 的固定衰减先验缺乏 softmax 注意力的灵活性，直接用于 HTR 会损失精度；同时图像与文本两种模态的融合需要专门设计，否则无法保持循环推理的线性复杂度。
- **整体含义**：论文试图证明"仅解码器 RetNet 能在 HTR 上达到 Transformer 级精度，同时获得线性时间/线性内存解码"，从而为 HTR 提供一条兼顾精度与部署效率的新路线。

## 2. 方法论

### 2.1 总体架构
- **仅解码器结构**：图像经 EfficientNetV2-S 编码为图像 token 序列，文本按字符级 tokenize，二者拼接后送入 L 层 RetNet 解码器，无编码器、无交叉注意力。
- **图像嵌入**：EfficientNetV2-S（ImageNet-1K 预训练，去掉分类头，全层 dropout=0.3），首层卷积宽度方向 stride 由 2 改为 1 以保留更多空间信息；特征图 reshape 为 `(w_visual, c×h)` 后经全连接映射到 `d_model`，加可学习位置编码。
- **文本嵌入**：字符级词表 + [SOS]/[EOS]/[PAD]，加正弦位置编码。

### 2.2 核心创新一：Attention-Retention Modality Fusion（ARMF）
- **动机**：对全部 token 用 softmax 会重新引入随文本长度增长的 KV 缓存；对全部 token 用 retention 又会削弱图文耦合精度。
- **做法**：按"键的来源"分区处理——
  - 图像键（image keys）：使用标准 softmax 注意力（图像 token 在推理时一次性并行计算并缓存，不随生成文本增长）；
  - 文本键（text keys）：使用因果、指数衰减的 retention（下三角衰减矩阵 D），保持可循环化。
- **并行形式**：`Ret = [softmax(Dots_img) | Dots_text ⊙ D]`，再乘 V；依赖掩码阻止图像 query 关注文本 key。
- **循环形式**：解码开始时一次性缓存所有层的 `K_img, V_img`；每步更新循环状态 `S_n = γ·S_{n-1} + k_n^T·v_n`，文本输出 `o_text = q_n·S_n`，图像输出 `o_img = softmax(q_n·K_img^T/√d)·V_img`，二者相加。
- **复杂度结论**：每步成本 O(N_I)（N_I 固定，实际为 O(1)），总解码复杂度由 O(N_T² + N_I·N_T) 降为 **O(N_I·N_T)，对生成长度线性**。

### 2.3 核心创新二：逐层 γ 缩放（Layer-wise Gamma Scaling / MARMF）
- **动机**：Transformer 注意力呈现"浅层局部、深层全局"的归纳偏置（论文用 DTrHTR 注意力图验证），而 RetNet 原始 γ 接近 1、偏全局记忆，与文本行识别中局部性更重要的特点不符。
- **公式**：`γ_{l,h} = 1 − γ_subtractor·(1 − l/(L−1)) − elinspace(log(1/32), log(1/512), H)_h`，即层越浅 γ 越小（强调局部），层越深 γ 越大（扩大感受野），同时保留头维度的多尺度变化。
- **配套简化**：去掉 RetNet 原始的 GroupNorm 与 Swish 门控，保持结构最小化。
- **图像侧先验**：对图像 token 也施加双向（bidirectional）衰减与逐层 γ 缩放（借鉴 RMT 的空间先验思想）。

### 2.4 训练细节
- 合成预训练：从 CC100 抽取文本、按 IAM 长度分布截断，用 11,954 种手写字体渲染约 **1700 万图文对**。
- 预处理：去斜（deslant）、高度统一 64 像素、白边填充至宽 2227、像素反转；六种增强各以 50% 概率施加。
- 优化：AdamW（weight decay 1e-3）、label smoothing ε=0.4、余弦退火学习率 1e-4→1e-6（每 30 epoch 重启）、retention/PFF dropout 0.3、embedding dropout 0.1。

## 6. 主要结论与发现

- **效率**：同等规模下，DRetHTR 比 DTrHTR 推理快 **1.6–1.9×**、显存少 **38–42%**（如 BASE：123s/22.14GB vs 233s/36.25GB，CER 2.26 vs 2.35）；比编码器-解码器 RetHTR 快约 3.2×、省 22% 内存。
- **精度**：IAM-A **2.26%**、RIMES **1.81%**、Bentham **3.46%** 为已报道最佳 CER；READ-2016 **4.21%** 具竞争力（略逊于 Coquenet et al. 的 3.59%）。
- **γ 调度有效**：原始 γ（4.65）→ 统一小 γ（4.60）→ 头级缩放（4.51）→ 逐层缩放（4.49），最终与 softmax Transformer 持平，且文本-文本交互保持无 softmax。
- **图像侧先验增益**：加入双向衰减与逐层 γ 后 CER 从 4.49 降至 4.35，且收敛更快。
- **分词权衡**：BPE 零样本更好（CER 9.12 vs 11.72），字符级微调后 CER 更优（2.26 vs 2.36）但 WER 更差（6.55 vs 4.81）。
- **beam 行为**：精度在 beam≈5 后饱和，继续增大 beam 只增加成本；RetNet 因固定大小循环状态，随 beam 增大比 KV 缓存 Transformer 扩展更友好。
- **定性发现**：模型并非单纯复制字形，而会调用语言先验（如将全大写图像输出为更自然的英文大小写）。

## 7. 优点

- **问题切口精准**：抓住 HTR 部署中 KV 缓存这一真实瓶颈，而非泛泛追求精度。
- **架构设计有针对性**：ARMF 的"模态分区归一化"巧妙地在保留循环可线性化能力的同时维持图文对齐，是本文最有价值的工程洞察。
- **归纳偏置的显式补偿**：用逐层 γ 缩放模拟注意力的局部→全局演化，并用注意力图可视化作为设计依据，动机与验证闭环。
- **公平的效率对比**：自建同参数量 Transformer 基线，避免与不同规模模型比较带来的偏差；同时报告时间、显存、CER 三维指标。
- **泛化验证扎实**：覆盖英/法/德、现代/历史、多作者/单作者四类场景，且不使用外部词典。
- **可复现性**：提供代码链接，训练细节（优化器、学习率、dropout、增强方式）交代较完整。

## 8. 不足与局限

- **消融隔离不足**：无法判定精度提升究竟来自 softmax 归一化范围的改变、γ 先验，还是二者交互（作者自认）。
- **未触及理论优势区间**：实验序列长度 n < d，未验证 n ≫ d 时循环解码的决定性优势；长序列对齐漂移未研究。
- **算力与训练成本报告不全**：缺训练时长、epoch 数、总 GPU 小时，复现成本难以预估。
- **预训练数据单一语言**：合成数据仅英文，非英文基准上的收益归因不清；1700 万合成对与 11,954 字体的构建成本也未量化。
- **精度非全面领先**：READ-2016 上落后于 Coquenet et al.（4.21 vs 3.59），Bentham 对比方法较少，部分基线（如 DTrOCR）仅报告 IAM。
- **应用限制**：仅验证文本行级任务，未涉及段落/页面级或版面复杂文档；字符级 tokenize 下 WER 偏高，对下游纠错需求更大；FP32 推理，未探索量化/半精度下的效率表现。
- **潜在偏差风险**：合成预训练字体与真实手写分布存在域差距；IAM 上"最高 CER 样本"分析为定性观察，样本量小。
