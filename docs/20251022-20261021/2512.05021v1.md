## 摘要
手写文本识别由于数据有限、书写风格差异大以及文字系统包含复杂变音符号而仍然具有挑战性。现有方法虽然部分解决了这些问题，但往往难以在没有大规模合成数据的情况下泛化。为应对这些挑战，我们提出HTR-ConvText，一种旨在捕获细粒度、笔画级局部特征同时保留全局上下文依赖的模型。在特征提取阶段，我们将残差卷积神经网络骨干与带有位置编码模块的MobileViT相结合。这使模型既能捕获结构模式，又能学习细微的书写细节。随后，我们引入ConvText编码器，这是一种在层次结构中结合全局上下文与局部特征的混合架构，可缩短序列长度以提高效率。此外，一个辅助模块注入文本上下文，以缓解连接主义时间分类的弱点。在IAM、READ2016、LAM和HANDS-VNOnDB上的评估表明，与现有方法相比，我们的方法取得了更好的性能和更好的泛化能力，尤其是在训练样本有限且手写多样性高的场景中。

## Abstract
Handwritten Text Recognition remains challenging due to the limited data, high writing style variance, and scripts with complex diacritics. Existing approaches, though partially address these issues, often struggle to generalize without massive synthetic data. To address these challenges, we propose HTR-ConvText, a model designed to capture fine-grained, stroke-level local features while preserving global contextual dependencies. In the feature extraction stage, we integrate a residual Convolutional Neural Network backbone with a MobileViT with Positional Encoding block. This enables the model to both capture structural patterns and learn subtle writing details. We then introduce the ConvText encoder, a hybrid architecture combining global context and local features within a hierarchical structure that reduces sequence length for improved efficiency. Additionally, an auxiliary module injects textual context to mitigate the weakness of Connectionist Temporal Classification. Evaluations on IAM, READ2016, LAM and HANDS-VNOnDB demonstrate that our approach achieves improved performance and better generalization compared to existing methods, especially in scenarios with limited training samples and high handwriting diversity.

## 1. 核心问题与研究背景

- **任务定位**：论文聚焦**行级（line-level）离线手写文本识别（HTR）**，目标是将手写文本行图像转换为对应字符序列。行级识别在标注成本与上下文信息量之间取得实用平衡。
- **核心挑战**：
  - 手写风格、书写工具、扫描条件差异巨大；
  - 部分语言（如越南语）存在大量**堆叠变音符号**，需要笔画级细粒度判别；
  - 训练数据有限，难以支撑大规模模型泛化。
- **现有方法的不足**：
  - **CNN/RNN（CRNN）类**：难以区分曲率、倾斜、连笔、笔画粗细等细粒度特征；且依赖 CTC 解码，缺乏语言上下文建模，准确率常低于注意力方法。
  - **Transformer/ViT 类**：擅长全局依赖，但缺乏局部归纳偏置，需海量数据（如 TrOCR 用 7 亿+合成图，DTrOCR 用近 20 亿图）才能泛化，不适合低资源 HTR。
  - **全卷积网络（FCN，如 OrigamiNet、VAN）**：并行性好，但可能限制长程上下文建模。
  - **混合注意力-卷积块**（源自语音领域的 Conformer 等）已在 ASR 成为主流，但**尚未被系统应用于 HTR 的视觉与空间挑战**——这是论文明确指出的研究空白。
- **整体含义**：论文试图在**不依赖预训练、合成数据与额外前后处理**的前提下，用一个紧凑的混合 CNN–ViT 架构同时兼顾局部笔画细节与全局上下文，并通过训练期文本先验弥补 CTC 的语言建模弱点。

## 2. 方法论

### 2.1 总体流程
输入归一化行图像 \(I \in \mathbb{R}^{H\times W}\) → CNN 提取器得到二维特征图 \(F\) → 按行展平为序列 \(X=\{x_i\}_{i=1}^{L}\) → 多头自注意力+卷积块处理为上下文感知 token → 投影为逐帧字符 logits → CTC 解码。训练时额外接入**仅训练期使用的文本上下文模块（TCM）**，推理时丢弃。

### 2.2 MVP Block（特征提取）
- 以 **ResNet-18** 为主体，保留其堆叠卷积层以获取鲁棒的局部特征与层次表示。
- 在 ResNet 后段**交错插入 MobileViT Block**，融合 CNN 的局部性与 ViT 的全局上下文。
- 由于 MobileViT 使用 Fold/Unfold 在 2D 特征图与序列间转换，常规三角函数位置编码不适用，故采用 **Conditional Positional Encoding（CPE）**，更适合带空间维度的特征。

### 2.3 ConvText 编码器
- **混合 ConvText Block**（受 Conformer 启发但结构不同）：顺序为 **MHSA → FFN → 深度可分离卷积 → 第二个 FFN**，而非 Conformer 的 Macaron 结构，以避免结构冗余。
  - 采用 **post-LayerNorm**、每个子模块的**可学习残差缩放（LayerScale）**、**Stochastic Depth（Drop Path）** 正则。
  - 卷积子块用 **SiLU 激活 + 深度可分离卷积堆叠**替代计算昂贵的 GLU，降低参数量、提升小数据训练稳定性。
  - 使用**相对正弦位置编码**（而非 HTR-VT 的固定正弦编码），以适应层次结构中序列长度变化、泛化到任意宽度文本行。
- **层次化 U-Net 结构**：
  - 在原始分辨率 \(L=128\) 处理，随后用步长 1D 卷积下采样至 \(L'=64\)；
  - 大部分深度（4 个 block）在压缩潜空间执行，将注意力计算成本约降至 1/4，同时扩大有效感受野；
  - 最后最近邻上采样并与高分辨率特征残差融合，恢复字符边界所需的细节。
- **形式化定义**（单个 block 将 \(x_0\) 映射为 \(y\)）：
  - \(x_1 = \text{LN}(x_0 + \text{LayerScale}_{attn}(\text{DP}(\text{MHSA}(x_0))))\)
  - \(x_2 = \text{LN}(x_1 + \tfrac{1}{2}\text{LayerScale}_{ffn1}(\text{DP}(\text{FFN}(x_1))))\)
  - \(x_3 = \text{LN}(x_2 + \text{LayerScale}_{conv}(\text{DP}(\text{Conv}(x_2))))\)
  - \(y = \text{LN}(x_3 + \tfrac{1}{2}\text{LayerScale}_{ffn2}(\text{DP}(\text{FFN}(x_3))))\)

### 2.4 文本上下文模块（TCM，仅训练期）
- **上下文构造**：对每个真值字符 \(c_i\)，取左窗口 \(S^l_i=(c_{i-k},...,c_{i-1})\) 与右窗口 \(S^r_i=(c_{i+1},...,c_{i+k})\)，经嵌入 + 轻量 1D 卷积 + 线性投影聚合，并加入**可学习方向偏置** \(b_l, b_r\) 区分左右来源：
  - \(\tilde q^l_i = \text{LN}(W_t q^l_i + b_l)\)，\(\tilde q^r_i = \text{LN}(W_t q^r_i + b_r)\)
- **融合方式**：通过**交叉注意力**将文本上下文与视觉 token 对齐，再以逐元素相乘融合，得到条件化表示 \(z^l_i, z^r_i\)，共享线性分类器输出 logits。
- **辅助任务**：仅用视觉特征 + 周边文本预测中心字符 \(c_i\)，迫使编码器学到与语言上下文一致的视觉表示。
- **损失函数**：
  - 主损失：\(\mathcal{L}_{ctc} = \text{CTCLoss}(\tilde Y_{ctc}, Y)\)
  - 辅助损失：对左右方向逐位置交叉熵 \(l^l_i, l^r_i\) 做带掩码（有效字符 \(w_i=1\)，padding 为 0）的加权平均，分母为 \(2\sum_j w_j\) 做长度/批大小归一化。
  - 总目标：\(\mathcal{L} = \lambda_{CTC}\mathcal{L}_{CTC} + \lambda_{TCM}\mathcal{L}_{TCM}\)
- **关键设计**：TCM 推理时移除，不引入自回归解码的延迟开销。

## 6. 主要结论与发现

- **IAM**：CER 4.0%、WER 12.9%，较此前最优 HTR-VT（4.7%/14.9%）分别降低 0.7 与 2.0 个百分点，取得新 SOTA。
- **LAM**：CER 2.7%、WER 7.0%，首次突破 3.0% CER 门槛，作者称接近该领域"人类级精度"。
- **READ2016**：CER 3.6%、WER 15.7%，优于 HTR-VT（3.9%/16.5%），跨历史手写风格泛化良好。
- **HANDS-VNOnDB**：仅 4,433 训练样本下 CER 3.45%、WER 8.9%，显著优于 HTR-VT（4.26%/11.2%），验证低资源 + 复杂变音场景有效性。
- **消融结论**：ConvText Block 带来最大单项增益（CER 6.25%→4.87%），TCM 进一步降至 4.19%，MVP Block 最终达 4.02%；CPE 在位置编码中取得最佳 CER/WER 平衡。
- **注意力分析**：基线注意力高度局部化（几乎只关注自身 token）；加入 ConvText 后扩展到邻域；加入 TCM 后进一步覆盖语义相关区域；最终配置达到局部聚焦与全局覆盖的平衡。
- **误差分析**：残余错误主要源于数据固有难点——不规则字形、连笔粘连（如 n/m 混淆）、文本遮挡/退化、越南语变音符号过密过淡，而非架构缺陷。

## 7. 优点

- **架构设计有针对性**：MVP Block 将 MobileViT 嵌入 ResNet 后段，兼顾局部归纳偏置与全局建模，且用 CPE 解决 Fold/Unfold 结构下的位置编码不适配问题，工程考量细致。
